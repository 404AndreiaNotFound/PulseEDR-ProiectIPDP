# PulseEDR Desktop

WPF frontend for the PulseEDR Light EDR Security Coach.

## Requirements
- .NET 8.0 Windows
- PulseEDR API running on http://localhost:5015

## Running
dotnet run --project src/PulseEDR.Desktop

## Features
- Dashboard with live security metrics
- Run scans and view risk scores
- Browse alerts with severity filtering
- JWT authentication
